# Changelog

## 0.1.0 — 2026-11-05

Primera versión de Mukure para macOS Apple Silicon.

- Reproducción de videos locales, archivos `.torrent` y enlaces magnet.
- Selección de videos dentro de un torrent y reproducción durante la descarga.
- Conversión de formatos con FFmpeg y FFprobe incluidos.
- Subtítulos SRT/WebVTT, pistas de texto integradas y ajuste de sincronización.
- Búsqueda automática en OpenSubtitles y SubtitleDB; conexión opcional a SubDL y Wyzie.
- Controles de reproducción, ventana redimensionable y pantalla completa con ocultamiento automático.
- Soporte experimental de Chromecast, con envío directo, conversión HLS y subtítulos externos.
- Almacenamiento de claves de API en el Llavero de macOS.
